# GitHub ve Netlify yükleme

## GitHub bağlantılı Netlify sitesi

1. ZIP dosyasını önce bilgisayarınızda açın. ZIP'i GitHub deposuna tek dosya olarak yüklemeyin.
2. Açılan klasördeki `index.html`, `styles.css`, `app.js`, `netlify.toml`, `manifest.webmanifest`, `icon.svg` ve `README.md` dosyalarını GitHub deposunun ana dizinine yükleyin.
3. GitHub eski dosyaların değiştirileceğini gösterdiğinde değişiklikleri kaydedin.
4. Netlify ayarlarında Base directory boş, Build command boş ve Publish directory `.` olmalıdır.
5. Netlify'da yeni GitHub commit'i için deploy başlatın.

## Netlify'a doğrudan yükleme

Netlify Deploys sayfasına bu ZIP dosyasını doğrudan sürükleyebilirsiniz. `index.html` ZIP'in ana dizinindedir ve herhangi bir build komutu gerekmez.
